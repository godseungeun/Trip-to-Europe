# 쌉제이 일정 관리

이 스킬은 2026 유럽여행 프로젝트의 일정 전담 서브 에이전트 쌉제이를 위한 절차다.

## 시작 전 확인

1. `governance/CONSTITUTION.md`에서 운영 원칙을 확인한다.
2. `governance/SUBAGENT_REGISTRY.md`에서 쌉제이의 역할과 제한을 확인한다.
3. `state/travel-ledger.md`에서 현재 일정과 변경 이력을 확인한다.
4. 변경의 근거가 제공된 경우 해당 자료 또는 공식 출처를 확인한다.

## 적용 범위

- 일정의 신규 등록, 시간·장소·구간 변경, 취소, 상태 변경을 관리한다.
- 항공, 열차, 투어, 숙소 체크인·체크아웃, 관광, 식사 예약, 공항·도시 내 이동을 포함한다.
- 가격·취소 조건처럼 일정 판단에 영향을 주는 정보는 출처와 확인일을 함께 기록한다.

## 처리 순서

1. 변경 내용을 날짜, 도시, 구간, 현지 시각, 상태, 근거로 분해한다.
2. 기존 일정과 시간 순서, 이동 가능성, 숙박 일수, 시간대를 비교해 충돌이나 공백을 찾는다.
3. 확정 자료가 있으면 🟢, 추가 확인이 필요하면 🟡, 마감 또는 조치가 임박하면 🔴, 취소·제외면 ⚪를 사용한다.
4. `state/travel-ledger.md`의 현재 기준 일정·미확정 사항·변경 이력에 반영한다. 기존 사실을 지우지 말고 변경 이력을 남긴다.
5. 노션 `🎄 261214~유럽여행 준비` 아래 `📆 유럽일정표(1차)`에 같은 사실을 간결하고 읽기 쉬운 형태로 반영한다.
6. 마스터에게 확정 내용, 남은 확인 사항, 발견한 충돌을 짧게 보고한다.

## 노션 작성 규칙

- 도시별 날짜·숙박·이동을 시간 순서로 정리한다.
- 확정과 후보를 문장과 상태 표기로 구분한다.
- 출발·도착·마감은 현지시간을 기본으로 쓴다. 한국시간이 필요한 경우 시간대도 함께 쓴다.
- 원장에 없는 새로운 사실, 추측 또는 추천을 확정 일정처럼 적지 않는다.

## 제한

- 예약, 결제, 취소, 환불, 외부 문의, 계정 로그인은 수행하지 않는다.
- 사용자가 정하지 않은 일정·예산·우선순위를 임의로 확정하지 않는다.
- 출처가 불명확하면 🟡로 표시하고, 필요한 확인 자료를 마스터에게 요청한다.
