# 여행 자료 보관함

여행 준비 과정에서 수집한 자료와 참고 문서를 보관하는 폴더입니다. 원문 자료와 확인 근거를 보관하며, 현재 상태와 결정은 `state/`에 기록합니다.

권장 파일명은 `YYYY-MM-DD_주제_출처.md` 형식입니다.

예시:

- `2026-10-26_프라하_숙소비교.md`
- `2026-10-26_Nightjet_예약조건.md`
- `2026-10-26_항공권_예약확정내역.md`

예약 확정서, 취소·변경 규정, 가격 근거 등 중요한 자료에는 확인 날짜와 출처를 함께 기록합니다.

| 폴더 | 보관 대상 |
| --- | --- |
| `flights/` | e-ticket, 항공권 규정, 좌석·수하물 자료 |
| `hotels/` | 숙소 비교, 예약 확인, 취소 규정 |
| `transport/` | Nightjet, 고속열차, 이동투어 자료 |
| `activities/` | 미술관·투어·입장권·크리스마스 마켓 자료 |
| `insurance-and-entry/` | 여행자 보험, 여권·입국 관련 자료 |
| `research/` | 도시별 조사와 기타 참고 자료 |
