# 2026 유럽여행 프로젝트

2026년 12월 14일~27일, 엄마와 딸이 프라하·빈·피렌체·로마를 여행하기 위한 준비 프로젝트입니다.

## 시작하기

1. 운영 원칙은 [헌법](governance/CONSTITUTION.md)에서 확인합니다.
2. 현재 일정과 확인이 필요한 항목은 [여행 기록 원장](state/travel-ledger.md)에서 확인합니다.
3. 수집 자료는 `docs/`의 주제별 폴더에 저장합니다.
4. 사용자용 최신 일정은 Notion의 `📆 유럽일정표(1차)`에서 확인합니다.

## 폴더 안내

| 폴더 | 용도 |
| --- | --- |
| `governance/` | 헌법과 서브 에이전트 등록부 |
| `state/` | 최신 상태, 결정, 변경 이력의 원본 기록 |
| `docs/` | 항공·숙소·교통·관광 등 수집 자료와 근거 |
| `outputs/` | 일정표, 예산표, 체크리스트, 보고서 |
| `.codex/skills/` | 반복 업무를 위한 프로젝트 전용 Codex 스킬 |
